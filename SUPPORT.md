## 🐛 Bug Reports

If `hydra-umc-local-technician contracts validate` accepts a document it
should reject (or the reverse), if `redact_secrets()` misses a real
secret shape, or if the injection-defense boundary (`knowledge/trust.py`)
behaves unexpectedly, please open a **GitHub Issue** in this repository -
include the exact command you ran, the payload/document involved (with
any real secret redacted first), and its full, real output.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?

- This is Fase 0 (inventory and security baseline) of a six-phase plan -
  it cannot yet run an inference engine, retrieve indexed knowledge,
  execute a real tool, or integrate with HYDRA-UMC-SERVER. Please do not
  open an Issue asking it to observe, diagnose, or act on a real
  ecosystem component; see the README's own Roadmap section for what is
  planned and when.
- This project coordinates with other real HYDRA-UMC/URTC projects
  (HYDRA-UMC-OPS-AGENT, HYDRA-UMC-SDK, HYDRA-UMC-DEV-SERVER, etc.) - a
  real bug inside one of THOSE projects' own code belongs on their own
  issue tracker, not this one's.
